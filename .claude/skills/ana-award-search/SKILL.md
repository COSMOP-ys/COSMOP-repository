# ANA 特典航空券（国際線）空席検索

ユーザー本人のブラウザ（Claude in Chrome、または Claude デスクトップアプリの内蔵ブラウザ）で
ANA 公式サイトを操作し、特典航空券の空席候補を一覧にする。**検索だけを行い、予約・発券・支払いは絶対にしない。**

## 0. 準備

1. `ana_award_search/config.md` を読み、検索条件（区間・期間・クラス・人数）を確認する。
2. `ana_award_search/results/` にある最新の結果ファイルがあれば読み、前回の空席を把握しておく。
3. 使うブラウザ機能のスキル（`anthropic-skills:chrome-browser` または `anthropic-skills:built-in-browser`）を先に読む。

## 1. ログイン

- ANA マイレージクラブへのログインは**ユーザー本人にしてもらう**。お客様番号・パスワード・認証コードを Claude が入力・保存しない。
- 未ログインならログイン画面を開いた状態で止まり、「ログインをお願いします。終わったら教えてください」と伝えて待つ。

## 2. 検索

- ANA サイトの「国際線特典航空券」の予約・空席照会画面から検索する。
- 往復で検索する。日付を変えて探せるカレンダー表示（前後の日付の空席がまとめて見える表示）があれば必ず使い、少ない検索回数で期間全体を網羅する。
- `config.md` の空港の組み合わせをすべて調べる。都市単位（東京 / 台北）で指定できればまとめて検索してよい。
- ANA 運航便だけでなく、提携便（EVA Air など）が表示されればそれも記録する。
- **アクセスはゆっくり行う**：検索と検索の間は数秒以上あける。短時間に大量の検索をしない。
- 画像認証、アクセス制限、エラー画面が出たら、**その場で検索を止め**、それまでの結果を保存してユーザーに報告する。回避しようとしない。
- 予約の確定・座席の仮押さえ・支払いに進むボタンは押さない。空席状況の確認に必要な画面までで止める。

## 3. 記録

1 件ごとに次を記録する。表示されない項目は「-」にする。

| 項目 | 例 |
| --- | --- |
| 方向 | 往路 / 復路 |
| 日付 | 2026-11-03 (火) |
| 区間 | HND → TSA |
| 便名 | NH0000 |
| 運航会社 | ANA / EVA Air など |
| 出発 → 到着 | 08:00 → 11:00 |
| 空席状況 | 空席あり / 残りわずか / キャンセル待ち可 など、サイトの表示どおり |
| 必要マイル | サイト表示どおり（往復合計で表示される場合はそう注記） |

## 4. 出力

1. 結果を `ana_award_search/results/YYYY-MM-DD.md`（検索した日付）に保存する。先頭に検索日時と条件を書く。
2. チャットには次の順で短く出す。
   - **新しく空いた候補**（前回の結果ファイルになかったもの）
   - **往路の空席一覧** と **復路の空席一覧**（日付順の表）
   - **組み合わせ候補**：往路と復路の両方に空席がある日付の組み合わせのうち、よさそうなものを数件
   - 検索できなかった区間・日付と、その理由
3. 空席がまったくなかった場合も、検索した範囲を明記して「空席なし」と報告する。
4. 予約はユーザーが自分で行う。必要なら予約画面の開き方だけ案内する。
