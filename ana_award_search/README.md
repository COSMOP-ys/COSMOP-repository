# ANA 特典航空券 空席検索（ブラウザ操作版）

Claude が**あなたのパソコンのブラウザ**で ANA 公式サイトを操作し、国際線特典航空券の空席候補を一覧にする仕組み。

- 検索条件：[`config.md`](config.md)
- 手順（Claude 用）：[`../.claude/skills/ana-award-search/SKILL.md`](../.claude/skills/ana-award-search/SKILL.md)
- 検索結果：`results/YYYY-MM-DD.md`

## 使い方

1. パソコンでこのリポジトリを clone（または pull）する。
2. Claude デスクトップアプリでこのフォルダを開いてセッションを始める。
   ブラウザ操作には、Chrome 拡張「Claude in Chrome」かデスクトップアプリの内蔵ブラウザを使う。
3. `/ana-award-search` と入力する。
4. ANA のログイン画面が出たら、自分でログインする（Claude はパスワードを入力しない）。
5. 検索が終わると、チャットに空席一覧が出て、`results/` に保存される。

### 定期的に実行したい場合

同じセッションを開いたまま `/loop 1d /ana-award-search` のように実行すると、1 日ごとに繰り返す。
前回の結果ファイルと比べて、新しく空いた席を先頭に出す。

## 制限

- パソコンとブラウザが起動している必要がある（クラウドからは ANA のサイトを操作できない）。
- ログインや二段階認証は本人の操作が必要。
- 期間が長いので、1 回の検索に数十分かかることがある。
- ANA サイトの画面が変わったり、アクセス制限が出たりした場合は、途中で止めて報告する。
- 検索のみ。予約・発券は自分で行う。
